ML Classification Project

Overview

This project demonstrates a Machine Learning Classification model using the Iris Dataset.

Dataset

- Iris Dataset
- 150 samples
- 4 features
- 3 target classes

Algorithms Used

1. Logistic Regression
2. Random Forest Classifier

Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Cross Validation Score

Tools Used

- Python
- Google Colab
- Scikit-learn
- Matplotlib

Project Files

- classification.ipynb
- report.pdf
- README.md

Conclusion

The models were trained and evaluated on the Iris dataset. Random Forest achieved better performance compared to Logistic Regression.
